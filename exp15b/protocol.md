# Exp15b 冻结前协议

训练保持 Exp15：CIFAR-100/ViT-Tiny、SST-2/BERT-Tiny，5 epoch、逻辑批次 1000，CV 物理批次 250、NLP 1000。CV 搜索/复核 225 步、正式 250 步，NLP 全阶段 310 步。β₁=0.9、β₂=0.999、weight decay=0；STP 分母常数 CV 0.05、NLP 0.01。原五方法代码由 Exp15 本地复制并改包名，保留公式、数据和模型处理。

`momentum+iid` 使用原空间逐样本裁剪和无偏差修正更新：

\[
\tilde g_t=(\sum_i\operatorname{clip}(g_{t,i};C)+Z_t)/1000,\quad
m_t=0.9m_{t-1}+0.1\tilde g_t,\quad x_t=x_{t-1}-\eta m_t.
\]

各步 Z 独立。使用独立 torch.Generator，seed=训练种子+1；IID 系数仅为 [1]，不保留历史创新。每个逻辑批次合并全部物理批次后只抽取一次噪声，先加到梯度和再除以 1000。相关组与 IID 可共享底层标准正态创新，输出轨迹和数值标准差不同。

策略 S=I_T。每个记录五轮每轮参与至多一次，各次裁剪贡献范数至多 C。无论参与位置是否跨轮固定，单位策略下平方敏感度至多 5，五次满范数贡献可取到，因此敏感度 √5；实际数据每轮复用同一打乱顺序，符合固定位置约束。通过与 Exp15 相同的 GDP δ(μ,ε) 求解 ε=8、δ=10⁻⁵ 的 μ，创新标准差 σ_sum=C√5/μ。完整噪声协方差 σ_sum²I_T，平均梯度噪声协方差除以 1000²。绝不沿用四频带校准幅度。

相关五组保持 Exp9 Momentum-Bias 四频带系数 d 和策略 S=D⁻¹，从已验证历史矩阵读取并按 C/R 重新校准。完整协方差为 σ_sum²DDᵀ；实际参数轨迹工作负载包含 0.1 因子，并区分是否一阶偏差修正。相关滤波器未针对无修正 Momentum 单独优化。每次训练保存 d、S、实际 workload、标准差、隐私预算和矩阵哈希，报告导出完整协方差及其哈希。

初始化、训练顺序、CV 增强和 NLP Dropout 按 Exp15 约定配对。smoke 对六方法核查初始化、顺序、非噪声随机流和独立噪声生成器状态；IID 在 CV/NLP 各复跑一次，模型逐张量完全一致。原五组的全部 smoke 与历史检查点逐张量完全一致才复用历史训练。

CV momentum 和 momentum+iid：C=0.3 时 lr∈{2,3,4}；C=1 时 lr∈{1,2,3,4}；C=3 时 lr∈{0.5,1,2}。其余四组：C/R=0.3 时 lr∈{1,2,3}；C/R=1 时 lr∈{0.4,0.6,0.8,1}；C/R=3 时 lr∈{0.25,0.5,0.75}。NLP 六组均 lr∈{0.15,0.20,0.30}、C/R∈{1,5,10,20,40}。

保留历史 90 个候选，与扩展 150 个去重，重合 16 个，新增 134 个，总候选 224。搜索 seed=20261101，A 固定 C/R=1，B 使用所有有效候选。按准确率降序、交叉熵升序、trial ID 升序各选前二；共享候选去重后追加 seed=20261102/20261103，最多 96 次。候选必须三个种子均完整且有限，以三种子平均准确率、平均损失、原搜索 trial ID 排序选最终配置。正式种子为 20261111–20261120，最多 240 次；精确相同配置去重及验证后复用历史正式训练。

固定超参数噪声对照覆盖两方法所有匹配任务/lr/C/seed 的搜索和复核结果，标注实际种子数和内部验证范围；正式配置恰好相同则提供正式匹配比较。独立调参后的正式十种子比较独立报告。保持任务书主实验最多 240 次，不为构造额外受控十种子对照追加未规定训练。两类估计的评价集和统计支持必须明确区分。

使用 add/remove zero-out 邻接、五轮固定参与约束，不使用采样放大；每次运行独立验证完整训练 ε=8。内部验证按原协议视为公开；原始未加噪训练诊断为本地私有审计产物，不声明它们可按训练预算发布。搜索、复核和选参不整体声明 ε=8。
