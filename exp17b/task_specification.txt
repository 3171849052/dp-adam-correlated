## 三、算法定义

保留标准 Adam 状态：

m_t = β1 m_(t-1) + (1-β1)x_t

v_t = β2 v_(t-1) + (1-β2)x_t²

M_t = m_t/(1-β1^t)

V_t = v_t/(1-β2^t)

参数固定：

- β1 = 0.9
- β2 = 0.999
- Adam ε = 1e-8
- weight decay = 0

定义：

A_t = β1 m_(t-1)/(1-β1^t)

B_t = (1-β1)/(1-β1^t)

K_t = β2 v_(t-1)/(1-β2^t)

D_t = (1-β2)/(1-β2^t)

当前梯度输入的 Adam 标量更新函数：

f_t(u) = (A_t+B_t u)/(sqrt(K_t+D_t u²+rν²)+1e-8)

其中 ν² 是每个私有梯度坐标的高斯噪声方差。

所有算法使用完全相同的一阶矩和二阶矩状态更新，只改变最后的更新方向。

### 方法一：Smooth Adam

d_t = f_t(x_t)

这是最重要的对照组。

当 r=0 时，应退化为标准 Adam。

### 方法二：LC-α

使用 Exp17 中已经验证过的解析二阶导数：

d_t = f_t(x_t) - α(ν²/2)f_t''(x_t)

解析二阶导数为：

f_t''(x_t) =
2D_t M_t h'(V_t)
+4B_tD_t x_t h'(V_t)
+4D_t² x_t² M_t h''(V_t)

其中：

h(v) = 1/(sqrt(v+rν²)+1e-8)

必须验证新实现与 Exp17 的 LC 在 α=1、相同 r 时一致。

### 方法三：GH-α

令：

c = sqrt(3)ν

定义确定性三点高斯积分修正：

d_t =
(1+α/3)f_t(x_t)
-(α/6)[f_t(x_t+c)+f_t(x_t-c)]

这是当前高斯热算子的一阶逆热近似，三点积分使用固定节点与权重。

注意：

- 计算 f_t(x_t±c) 时必须使用相同的历史状态 A_t、K_t。
- 不得将扰动后的梯度写入 Adam 状态。
- 不得重新调用模型反向传播。
- 不得重新裁剪梯度或增加隐私梯度查询。
- 不允许额外随机高斯探针。
- GH 不需要 Hessian 或自动微分。
- 每个坐标只计算三个标量函数值。

GH 修正与 LC 修正都仅依赖已经私有化的梯度和状态。

α=0 时，LC 和 GH 都必须严格退化为对应 r 下的 Smooth Adam。

本次不实现 HC，不增加历史曲率状态。
