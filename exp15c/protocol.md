# Exp15c 固定协议

只训练 `adam-no-noise`、`momentum-no-noise`、`momentum-mf-native`。

- CIFAR-100 + 本地 ViT-Tiny；SST-2 + 本地 BERT-Tiny。离线模式，显式本地读取，禁止下载。
- 沿用 Exp15b 的全参数 FP32 模型实现、初始化、Exp9 中固定划分、随机排列、每 epoch 相同数据顺序、CV 增强及 NLP 逐步 dropout 种子。每个 trial 记录初始化/分类头/训练顺序哈希、增强或 dropout 随机轨迹。
- 五轮；逻辑 batch=1000；CV 物理 batch=250，NLP=1000。CV 搜索/复核 225 步、正式 250 步；NLP 始终 310 步。无学习率调度，weight_decay=0。
- 标准 Adam：β1=.9、β2=.999、eps=1e-8，两阶偏差修正。Momentum：m=.9*m+(1-.9)*g，参数加上 -lr*m，无偏差修正，与 Exp15b 浮点运算次序相同。
- 无噪声组用每个物理 batch 的交叉熵梯度和，累积至 1000 再除以 1000；没有任何每样本裁剪、DP wrapper 或噪声对象。裁剪比例和隐私预算记为空，不能解释成 ε=0 DP。
- DP 组沿用 Exp15b Ghost clipping（含重复 token、padding-aware Embedding 范数）；在原始梯度空间裁剪，再累积、添加 FIR 噪声，除以 1000。

MF 设计：D 是四个系数的下三角 Toeplitz FIR，d0=1，S=D⁻¹。W[t,s]=(1−.9^(t−s+1))/(1−.9)，s≤t，其余为零。复用 Exp15b 完整矩阵目标 sensitivity(S)² ||WD||F²/T 和两个固定起点 Nelder-Mead；固定五轮参与敏感度使用参与列 Gram 绝对值和上界，不使用采样放大。分别优化 T=225、250、310。噪声种子为 trial.seed+1，独立于训练/dropout 随机流。

单次训练 ε=8、δ=10⁻⁵，五轮固定参与，add/remove zero-out 邻接。由新 S 的敏感度和目标 GDP μ 重新求 innovation_std=C*sensitivity(S)/μ；不复用历史标准差。保存每步前缀预算并核对完整训练预算。忽略的常数 (1−β)=.1 不改变最优滤波器；报告实际累计动量噪声 MSE 时包含 .1²、C²、1000² 归一化，参数轨迹误差还须乘 lr²。

正式 CV 使用全部 50000 个训练样本并在官方 test 上评价；NLP 沿用固定 62000 个训练样本，在官方 872 例验证集上评价。搜索/复核不读取官方评价结果，smoke 只使用 64 个内部验证例。历史官方评价集已使用，本次不是新盲测。内部验证假定公开；没有整个超参数搜索、复核和十次重复训练的组合隐私声明。原始裁剪诊断仅作私有审计产物。

输出十种子准确率均值、样本标准差 (ddof=1)、Student-t 95% CI，交叉熵、裁剪比例、最优 LR/C、MF workload MSE。差值使用相同种子配对并验证初始化/数据顺序/非噪声随机轨迹；配对 CI 针对逐种子差值计算。比较无噪声 Adam/Momentum、无噪声与 DP-MF、Exp15c 和历史 Exp15b Momentum+MF。固定相同 LR/C 的搜索与双方都有的复核逐对输出；如果正式最优参数不同，没有固定 LR/C 十种子证据，不补训历史方法。

搜索/复核阶段仅对 summary 明确记录的 `non_finite`（FloatingPointError）按无效超参数候选排除，保留 traceback/日志/任务现场并继续其余任务，恢复时不重试。已完成且指标有效的候选参与排名；三种子复核中任一发散则该候选不参与选优；某组无有效候选时明确停止。正式阶段非有限值仍是致命错误，不排除任何正式种子。真实错误、OOM、哈希不一致或隐私校准异常均停止阶段；其他已启动任务可正常收尾，不启动新任务。没有静默跳过或自动重试。最终报告及审计包含计划数、完成数、发散排除数和原因。历史 Exp9/Exp14/Exp15/Exp15b 的文件大小及纳秒 mtime 在测试前、smoke 后、报告后核对。
