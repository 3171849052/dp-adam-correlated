# Exp18c 完整实验报告

完成时间：2026-11-05T15:27:41.928125+08:00。90/90 完整训练，30/30 入选检查点官方测试评价。

模型与 Exp18 相同：两层卷积小型 CNN，11,274 个参数。逐字节复用 Exp18b 的五份初始化；未使用 cache 中不兼容的 BERT/ViT 权重。五份按种子生成的初始化保存在 initializations/，每份由同一种子的六种方法和三个学习率共用。它们是随机初始化文件，不是预训练 cache 权重。

MNIST 54000/6000/10000，3 epoch、162 步，逻辑/物理 batch 1000、累积 1、FP32、无权重衰减。三个学习率完整网格，各优化器的 IID/B2LT 使用相同超参数。验证集最终准确率在两种噪声与五种子间等权平均选择；冻结 best_hyperparameters.json 后，每个入选种子检查点进行一次完整官方测试评价，无额外训练、无测试集调参。

隐私：每次完整训练 ε=3、δ=1e-5，GDP、增删零槽邻接、无采样放大。三份 B2LT 使用 Exp18 的原矩阵，T=162、K=P=54、Q=5；按本次 clip 重新计算噪声。90 次训练的组合隐私预算不等于 ε=3。验证集视为公开；原始训练损失与裁剪诊断是内部审计信息，不声明为额外 DP 发布。
